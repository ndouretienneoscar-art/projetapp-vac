# 🌿 Application Paroissiale – Gestion des Sacrements

Bienvenue dans cette application dédiée à la vie paroissiale. Elle permet aux prêtres, secrétaires et fidèles de gérer les demandes de sacrements avec fluidité, sécurité et chaleur spirituelle.

---

## ✨ Fonctionnalités

- 🔐 Authentification par rôle (prêtre, secrétaire, fidèle_demandeur)
-Possibilité de créer un nouveau compte, mais pas avec la même adresse Email
-Mots de passe cryptés
- 📋 Gestion des demandes : baptême, mariage, confirmation, messe
- 👁️ Interfaces dédiées avec filtres, pagination et mise à jour du statut
-Interface spéciale pour fidèle, pour prêtre et pour secrétaire
- 🧘‍♂️ UI spirituelle : messages apaisants, icônes animées, transitions douces
- 🛡️ Sécurité renforcée via middleware et API protégées
- 📦 Laravel + React + Axios + Postman
-Base de données MySql fontionnelle et interactive avec React, délivrant des données, mais aussi stockant des informations
